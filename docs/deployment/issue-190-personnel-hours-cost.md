# Personnel hours: hourly pay and cost

Deploy after the separate three-tab prerequisite (`codex/249-personnel-three-tabs`, commit 78e1a72). Deploy application code and compiled assets together. No migration, backfill, permission remap, persistent cache, new index or temporary nullability is introduced. Rollback uses the previous code and assets.

Intent: authorized Personnel hours viewers see current hourly pay on person rows and Scheduled / Approved cost beneath the existing hours cells. `team.hours_report.view` gates every report request; no new permission is added. `team.personal_info` continues to gate the separate member page. Reports remain readable on locked events. The role tooltip and report description explain the expanded report scope.

The existing assignment-minute query remains the single hours calculation. Cost uses each engagement's current decimal rate converted to integer cents in SQL. Summary / By team round each person's complete selected-range minutes times that rate, half up, before summing team and event totals. By shift rounds each person's shift cost before summing the shift. Calvin explicitly accepted differences between these scopes: two one-minute assignments at 0.30/hour cost 0.01 combined in the range report, versus 0.01 each in the shift report. `TeamScheduledHoursQuery::eventCostTotals()` supplies whole-event Budget figures independently of selected dates and filters, using whole-event person rounding. Approved cost is null until #205; there is no Unapproved cost field or scheduled fallback for Approved.

Hired zero-hour members and assigned members of any status retain the established report eligibility. Missing-rate counts include distinct eligible paid people, including zero-hour Hired members; a zero rate is valid. Volunteers retain hours but contribute no cost, and legacy volunteer rate values are not returned. All keeps configured zero-hour teams and unassigned shifts. Paid / Volunteers hide teams or shifts with no eligible matching people, preserving matching zero-hour people. Volunteers suppresses all displayed cost lines.

The employment filter is shared between all three tabs, restored from the URL, validated by Form Requests, and included in every request-cache identity and response check. Successful snapshots remain cached for the page visit without automatic refresh. A fresh request uses current rates; no new rate-edit invalidation is needed for this visit-only cache. Filtered Summary rows do not replace the full event team-picker catalogue. Opened shift totals reconcile with their loaded people. Failed requests retain the existing named Retry states and cannot populate another selection's cache.

The locked 64*3 frames guide the existing-cell desktop and phone layout. Retain shipped Personnel wording. Currency configuration is outside this slice; amounts show two decimals and no symbol because there is no event currency field. Budget UI, email/CSV, rate history, day rates, payroll, and worked-hour computation remain outside this change. #205's older fallback/separate-labour-cost wording must follow the newer confirmed two-cost contract when that feature lands.
